Set up your PingDuck agent

The agent runs in one container on an always-on box. It finds the devices your phone can't see and keeps watching when you're away.

Then open PingDuck on a phone on the same Wi-Fi and tap Find my agent. The app finds the agent and activates it. There's no code to copy.
App can't find it? Check the container is running (docker ps), that it uses host networking, and that the phone isn't on a guest Wi-Fi. If the box is on another VLAN, tap Use a pairing code in the app.
